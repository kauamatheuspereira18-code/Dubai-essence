# Dubai em Essence — Documentação do Projeto

## 1. Visão geral

A **Dubai em Essence** é uma loja virtual premium criada inicialmente para perfumes árabes, mas evoluída durante o desenvolvimento para contemplar também alguns perfumes/importados que aparecem nos prints do Instagram da loja.

O objetivo do projeto é transmitir:

- luxo;
- elegância;
- sofisticação;
- confiança;
- compra rápida pelo WhatsApp;
- experiência visual premium.

A loja foi desenvolvida com identidade própria, usando como referência apenas boas práticas de UX e estrutura de e-commerce, sem copiar identidade visual, código, textos ou elementos protegidos de terceiros.

## 8. Regras para imagens dos produtos

Após revisão, foi definido que as imagens devem mostrar apenas o produto.

### Permitido

- frasco do perfume;
- caixa original;
- kit original do próprio produto;
- fundo branco ou neutro;
- imagem de catálogo limpa.

### Não permitido

- atomizadores avulsos;
- amostras;
- objetos decorativos estranhos;
- banners;
- montagens confusas;
- mãos segurando;
- cenários de loja;
- fotos lifestyle carregadas;
- itens que não fazem parte do produto.

Quando não houver 3 imagens limpas diferentes, é aceitável repetir uma imagem limpa do produto em vez de usar uma imagem poluída ou errada.

## 17. Compra pelo WhatsApp

A compra principal é feita via WhatsApp.

Ao clicar em Comprar, o cliente é direcionado para o WhatsApp da Dubai em Essence com mensagem automática.

Formato da mensagem:

```txt
Olá! Vim pelo site da Dubai em Essence e tenho interesse no perfume: [NOME DO PERFUME]
```

Exemplo:

```txt
Olá! Vim pelo site da Dubai em Essence e tenho interesse no perfume: His Confession
```
